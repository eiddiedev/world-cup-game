# 《剑指美加墨》完整项目交接（2026-07-22）

## 1. 项目是什么

《剑指美加墨》是 2026 世界杯主题的像素足球经营与决策游戏。玩家选择国家队，从 35–40 人候选池征召 23 人，完成排兵布阵，并在持续运行的 11v11 2.5D 比赛中通过教练决策、换人和战术调整影响赛果。

最终产品不是演示页，主菜单固定为教练模式、球员模式、点球大战和设置。三种玩法最终共用同一套 Match Runtime、人物、球衣、球场、足球物理、球门、动态球网、相机、事件、比分和赛后链。

核心玩法离线权威。火山引擎 AI 只增强动态解说、建议、赛后复盘、球探报告和叙事；AI 失败或断网不能阻止比赛，也不能改变足球运动、决策 outcome、比分和存档。

当前位于“教练模式比赛核心收口”阶段，不再是早期 Runtime 技术验证。

- 42 个赛前、中场、加时阶段更衣室决策。
- 事件同源的比分、统计、播报、VAR、红黄牌、音效和场内事件素材。
- 雨天像素雨与本地双层雨声音效；音效开关可以同步停止和恢复雨声。

- 约 3 分钟有效比赛时间、上下半场补时、淘汰赛加时赛。
- 加时平局后的互动点球大战，以及独立点球大战入口。

未完成或未通过最终产品验收的部分：

- 53 个决策仍需逐项人工核对画面语义；“自动脚本齐全”不等于动作、路线和播报都正确。
- 加时与点球已经实现，但整届赛事中的转场、结算和存档仍需多轮浏览器验收。
- 红牌真实离场、跨场停赛、伤病/疲劳恢复和战术参数需要赛事级收口。
- 球员模式只有菜单、存档和数据契约，没有真正的直接操作层。
- 当前只有 10 队模板，最终 48 队内容尚未扩展。
- 火山 AI 增强、正式抖音候选包和第三方许可清单尚未最终完成。

## 3. 权威架构边界

React 外壳负责页面、阵容、赛事、决策 UI、比分展示、存档和赛后结算。HappySeed Runtime 负责场上 actor、足球、动作、物理、球门、动态球网与相机。`FormalMatchSession` 把 Runtime 真实事件转成比赛分钟、规则事件、决策机会、播报、统计和权威比分。

同一事实链必须是：

```text
Runtime 真实动作/位置
  → MatchRuntimeEventV1
  → FormalMatchSession
  → 决策触发 / 比分 / 播报 / 音效 / 赛后报告
```

禁止从播报文字或 decision ID 用正则反猜动作；禁止为了凑决策次数传送球员；进球只有 Runtime 越过门线后才能结算。

绝对不要修改：

```text
public/match-runtime-min/scripts/match.rebuilt.js
```

该文件是第三方物理核心。自有适配应写在：

```text
public/match-runtime-min/standalone-match.js
public/match-runtime-min/happyseed/runtime-v2.js
public/match-runtime-min/happyseed/runtime-v3.js
src/services/happySeedMatchRuntime.js
```

## 6. 数据与玩法现状

- 可玩球队：法国、巴西、阿根廷、葡萄牙、德国、日本、挪威、摩洛哥、新西兰、库拉索。
- 每队当前 38 人，征召 23 人。
- 教练模式比赛约 3 分钟有效时间；决策、暂停、转场时比赛时钟冻结。
- 常规时间淘汰赛平局进入 30 分钟加时，加时仍平进入点球大战。
- 更衣室决策覆盖开赛前、中场、加时前与加时中场。
- 最新算法基线见 `docs/balance/2026-07-20-algorithm-optimization-report.md`，不要只凭一场比赛调整全局概率。
