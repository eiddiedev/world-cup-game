# 剑指美加墨 — 算法优化报告（2026-07-20）

## 目标与方法

针对两个问题做数据驱动调优：

1. 比赛数据分布不稳定：场均进球、角球、点球、红黄牌波动大，强弱队胜率与冠军分布偏离真实世界杯。
2. 决策对比赛走向影响力不足：体验像 AI 模拟对战，用户的选择、战术调整、换人、排兵布阵没有真实主导比赛。

方法：新建全链路 Monte Carlo 仿真（`scripts/full-balance-sim.mjs`），直接调用生产同款决策引擎
（`executeDecision` / `resolveChoiceResult` / `resolveMatchPenaltyChoice`）与真实球员数据，
跑 10 支球队全部 90 个对阵 × 4000 场 = **360,000 场**，外加 **2,000 届**完整世界杯赛制锦标赛
（两组各 5 队单循环，前二进四强淘汰，平局点球近似）。多种子复核通过。

## 决策算法改动（`src/utils/decisionSystem.js`）

1. **默认进球转化率 `DEFAULT_GOAL_CONVERSION = 0.62`（新增）**：成功池摇中 goal 不再必进，
   选项可用 `goal_conversion` 单独覆盖。
2. **质量曲线 `conversion = base × (successProb × 2.0 − 0.5)`（新增）**：好选择执行到位、
   差选择转化腰斩——最优 1.47 球/场 vs 最差 1.23 球/场，胜率差 8.5%。
3. **球队档位因子 `teamTierFactor = clamp(0.5, 1.25, (teamAvgRating − 72) / 12)`（新增）**：
   弱队决策正确执行也打折，为副本成长留空间。
4. **只对本方进攻进球生效**：防守场景失球判定不受影响。
5. **成功率公式放宽**：`baseProb = 0.22 + attr/99×0.52`，封顶 0.86、封底 0.08。
6. **对手质量修正加强**：`opponentMult` 区间 [0.78, 1.18]，系数 0.005。

## 内容/数据改动

1. **日本队（`src/data/players/japan.js`）**：rating/spd/phy/tec/def 全员下调 6 点。
   夺冠概率 46.9% → 8.9%，落位到预期档位。
2. **德国队（`src/data/teams.js` 新增 `tacticalEfficiency: 0.85`）**：球员数值不动
  （纸面实力保留、上限高），但默认战术安排糟糕，夺冠概率 50.8% → 9.4%。
   玩家执教德国修战术可解锁上限——这是后续战术板/建队玩法的设计空间。
3. **仿真模型**：`scripts/full-balance-sim.mjs` 读取 `tacticalEfficiency` 并作用于攻防两端；
   锦标赛点球大战按 ELO 加权（不再 50/50）。

## 仿真模型说明

- 原生对战层：泊松进球，`λ = 0.8 × clamp(0.3, 3.0, exp((攻-防) × 0.05))`。
- 决策层：每场 5 保底窗口 + 自然触发（均值 6.60），72% 进攻 / 24% 防守 / 4% 其它，
  全部走生产同款决策引擎与真实 23 人名单。
- 复现：`node scripts/full-balance-sim.mjs --runs 4000 --seed 20260720`

## 残留问题与后续建议

1. 原生对战层（Pixi 物理）进球率为泊松近似校准，建议浏览器实测几十场原生比分后回填参数。
2. 最优/最差差距（0.24 球/场）仍受限于同场景选项共享关键球员的数据结构；
   若要更大差距，需在决策库为高/低风险选项配置更悬殊的结果池（内容改动）。
3. 阿根廷（45.1%）在第一集团内偏弱，因其 attack 均值（78.2）低于巴西（83.8）；
   属数据结构问题，如需调整另行评估。
4. 点球大战为 ELO 加权近似，后续可接入真实点球逻辑验证。
