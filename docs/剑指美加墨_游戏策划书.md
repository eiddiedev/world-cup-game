# 《剑指美加墨》游戏策划书

Targeting USA · Canada · Mexico

版本日期：2026-07-26
目标平台：H5 网页 / 抖音互动空间
技术栈：Vite + React 19 + 本地比赛 Runtime
当前规模：16 支可执教国家队 · 每队 24 人 · 10 套阵型 · 53 个关键决策场景

## 一、项目概述

### 1.1 游戏定位

《剑指美加墨》是一款像素风世界杯国家队经营与临场指挥游戏。玩家接受一支国家队的聘书，从征召球员、建设后勤、分析对手和排兵布阵开始，经过赛前更衣室、11v11 实时比赛、关键决策、换人与战术调整，最终完成一届可以被记录、复盘和收藏的世界杯征程。

游戏并不把足球简化成几张选择卡，也不让比赛只剩一段无法干预的动画。它希望把“做主教练”拆成一条完整因果链：准备会改变阵容，阵容会改变比赛，比赛会留下数据，数据会产生复盘，复盘又会影响下一场选择。

### 1.2 设计初心：重走意难平的来时路

世界杯结束以后，每个球迷都会留下自己的意难平。有人遗憾天才阵容没有兑现，有人等待“足球回家”，有人想看亚洲球队再向前一步，也有人只想让第一次站上世界杯舞台的小国赢下一场比赛。

因此，16 支球队不是换了国旗和球衣的同一套模板。每支球队都有独立的现实语境、预算、难度、阵容结构、默认阵型、球队技能、足协任务、聘书内容和结局评价。强队承受“不夺冠就是失败”的压力；弱队的一次首胜、一次小组出线，也可以成为值得收藏的历史。

## 二、完整游戏流程

### 2.1 一届世界杯的主循环

1. 选择国家队，阅读球队目标、难度、预算和球队性格。
2. 接受足协聘书，通过盖章完成主教练任命。
3. 从 24 名候选球员中征召阵容，在预算与位置深度之间取舍。
4. 投资医疗、营养、心理、数据、训练和球探部门。
5. 读取下一个对手的危险球员、阵型、弱点和门将倾向。
6. 选择阵型并拖拽 11 人首发，检查位置适配与阵容完整性。
7. 进入赛前更衣室，处理天气、媒体、伤病、队长和装备事件。
8. 在 11v11 比赛中调整战术姿态、完成换人，并处理关键决策。
9. 阅读赛后统计、教练建议与复盘，把结论带入下一场。
10. 推进小组赛与淘汰赛，最终进入球队专属结局和图鉴记录。

| 上游选择 | 进入的正式状态 | 下游结果 |

| 后勤升级 | 伤病、恢复、体力、士气、情报等级 | 赛前状态、连续作战能力、信息完整度 |
| 情报阅读 | 对手阵型、弱点、危险球员、门将倾向 | 阵型反制、盯防重点、点球方向选择 |
| 排兵布阵 | 11 人、位置、阵型、结构完整性 | 攻击、中场、防守和对手机会概率 |
| 更衣室选择 | morale / form / stamina | 关键决策成功率与球员当场表现 |

## 四、球员征召与阵容构建

### 4.1 24 人名单为什么不是摆设

每队 24 人由 2 名门将与 22 名场上球员组成。玩家必须至少建立 11 人首发，同时为伤病、停赛、状态波动、阵型切换和换人准备替补。预算不会允许把每个位置最贵的人全部买下，因此“最强首发、最深替补、最好门将”三者不能同时满足。

| 征召策略 | 大致可签人数 | 优势 | 风险 |
| --- | ---: | --- | --- |
| 高价核心优先 | 约 13 人 | 首发上限高、金卡能力集中 | 替补薄、伤停后结构容易断裂 |
| 主力与轮换平衡 | 约 15 人 | 能覆盖换人与状态轮换 | 必须放弃少数明星 |
| 低价深度优先 | 约 18 人 | 位置覆盖与替补数量充足 | 单个关键节点能力不足 |

### 4.2 球员属性与当场状态

| 属性 | 主要作用 | 典型影响场景 |
| --- | --- | --- |
| 速度 SPD | 突破、回追、反击、边路推进 | 单刀、边路套上、身后球 |
| 身体 PHY | 对抗、争顶、护球、铲抢稳定性 | 角球、禁区混战、最后一人防守 |
| 技术 TEC | 传球、射门、盘带、定位球处理 | 直塞、远射、任意球、点球 |
| 防守 DEF | 站位、封堵、门将扑救、解围 | 防线完整性、门将 1v1、解围 |
| 体力 STA | 持续跑动与下半场表现 | 高压、压上、加时、连续比赛 |
| 关键时刻星级 | 高压节点中的稳定性 | 点球、绝杀、VAR 后续、加时 |
| 状态 FORM | 将基础能力转成当场有效表现 | 赛前首发比较与赛后轮换 |

实际能力以基础属性为底，再结合状态、体力、位置适配和比赛阶段。状态好的替补可能胜过状态差的主力，这使每一场的首发选择都有意义。

### 4.3 金卡、像素球员与球衣系统

每队设置一名代表性金卡核心，使用风格化称号而非真实姓名，既形成贴纸册式收集记忆，也降低真人授权依赖。玩法层有 384 名球员，比赛美术通过纸娃娃部件、肤色/发型、号码、位置和球衣进行组合，避免为每人预烘焙整套动画。

当前球衣资产按 16 支可执教队管理，每队包含正式比赛所需的主客场、门将和角色部件；48 队数据只用于世界杯对手与赛程，不再作为 48 支可玩队扩展计划。

### 5.2 阵型反制关系

| 对手特点 | 推荐思路 | 原因 |
| --- | --- | --- |
| 三前锋拉开宽度 | 五后卫或双后腰保护 | 缩小禁区与边中结合空间 |
| 五中场控球 | 4-1-4-1 或 3-4-2-1 压迫出球 | 增加中场横向覆盖与前腰干扰 |
| 双前锋冲击中卫 | 额外后卫或后腰回收 | 防止两名前锋同时牵制中卫 |
| 五后卫低位 | 4-3-3 拉宽并增加二点球 | 通过宽度和持续压迫拆解密集防守 |
| 高位逼抢 | 稳守反击、快速越过第一线 | 利用对方压上后的身后空间 |

情报部门会读取对手真实阵型给出反制建议；是否采用仍由玩家决定。阵型介绍也在手机端完整保留，不把战术系统压缩成只有编号的按钮。

### 5.3 位置兼容度

有效评分采用 `球员评分 × 位置兼容度`。天然位置为 1.00；典型错位如下：

| 原位置 → 场上角色 | 兼容度 | 设计解释 |
| --- | ---: | --- |
| GK → GK | 1.00 | 天然门将 |
| DF → DF | 1.00 | 天然后卫 |
| MF → MF | 1.00 | 天然中场 |
| FW → FW | 1.00 | 天然前锋 |
| MF → DF | 0.55 | 可回撤，但缺乏专职防线习惯 |
| MF → FW | 0.68 | 技术型中场可前移 |
| FW → MF | 0.62 | 可参与进攻组织，防守贡献有限 |
| DF → FW | 0.42 | 可客串支点，终结能力受限 |
| 非门将 → GK | 最低 0.12 | 门将位置不可被高总评绕过 |

### 5.4 五档临场战术姿态

| 战术姿态 | 纵向位移 | 宽度 | AI 倾向 | 跑动风险 | 体力消耗倍率 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 全员压上 | +0.15 | 1.18 | 强进攻 | 1.28 | 1.45 |
| 进攻主导 | +0.07 | 1.10 | 进攻 | 1.14 | 1.20 |
| 攻守平衡 | 0.00 | 1.00 | 平衡 | 1.00 | 1.00 |
| 稳守反击 | -0.07 | 0.92 | 防守反击 | 0.88 | 0.82 |

压上会增加前场人数和进球机会，也会提高体耗并暴露身后；回收可以保护领先，却会牺牲宽度与持续进攻。战术不是一次性加成，而是随时可以调整、同时承担代价的比赛状态。

### 6.1 六大后勤部门

| --- | --- | --- | --- | --- |
| 医疗 | 轻伤恢复、降低伤病 | 伤病概率进一步降低 | 淘汰赛恢复、体耗减免、带伤接口 | 直接影响可用阵容与恢复 |
| 营养 | 开场体力 +5 | 开场体力 +8、降低连续疲劳 | 核心球员免疲劳接口 | 直接影响体力曲线 |
| 心理 | 降低士气衰减 | 点球稳定性提升 | 决赛压力免疫 | 直接影响士气与点球 |

| 训练基地 | 训练效率 +10% | 训练效率 +15%、随机状态提升 | 训练主题接口 | 直接/成长收益 |
| 情报部门 | 近期趋势 | 门将与惯用阵型 | 领先/落后时战术预判 | 信息收益 |

医疗、营养、心理和训练会直接改变正式状态；数据与情报不会暗改随机数，而是提供更好的决策依据。玩家只有真正换阵、换人、改变点球方向或调整战术后，信息才转化为胜率收益。

### 6.2 情报等级能看到什么

| 情报层级 | 新增信息 | 玩家可采取的行动 |
| --- | --- | --- |
| 无部门 | 对手名称与基础赛程 | 依靠通用阵型与经验 |
| 基础数据 | 对手强弱项、整体风格 | 选择更匹配的攻守思路 |
| 深度数据 | 危险球员、结构弱点、近期趋势 | 调整盯防、阵型与换人预案 |
| 完整情报 | 门将扑点倾向、惯用阵型、领先/落后战术 | 选择点球方向、反制阵型和临场预案 |

### 6.3 道具与装备系统

道具系统采用“准备与恢复”原则，不出售直接进球、直接胜利、裁判偏置或决策成功率。当前已完成数据合同、使用时机、目标、效果意图和公平边界；库存消耗与正式 Runtime 效果仍按接口逐步接入。

| 道具 | 使用时机 | 目标 | 效果意图 | 限制与代价 |
| --- | --- | --- | --- | --- |
| 运动饮料 | 赛前或两场之间 | 单名球员 | 恢复体力，单次上限 8 | 单场限用，不突破状态上限 |
| 冰袋 | 赛后 | 轻伤球员 | 轻伤恢复周期 -1 | 不能让重伤球员立即复出 |
| 球鞋 | 赛前装备 | 非门将球员 | 写入球鞋准备标签 | 后续效果必须附带体耗或次数取舍 |
| 门将手套 | 赛前装备 | 门将 | 写入门将专注标签 | 不保证扑救成功 |
| 战术板 | 赛前 | 全队 | 写入战术准备标签 | 不替玩家自动选择决策 |
| 训练器材 | 两场之间 | 训练组 | 记录训练进度 | 消耗时间，并可能累积疲劳 |

### 6.4 训练基地

训练基地既是成长入口，也是玩家模式的教学空间。玩家可以先熟悉移动、传球、射门、铲球、压迫和手柄输入，再进入正式比赛；经营层的训练升级则负责提高训练效率与状态收益。操作练习和数值成长使用同一套足球语言，避免教程与正式比赛割裂。

## 七、更衣室与天气系统

### 7.1 42 个更衣室场景

更衣室事件覆盖赛前、中场、加时和点球准备，内容包括媒体看衰、阵容泄露、供暖故障、长途飞行、球鞋磨脚、队长恶作剧、小球迷来信、雨战准备、门将装备、老将请战、换人名额和点球压力等。

| 阶段 | 主要问题 | 可影响状态 |
| --- | --- | --- |
| 赛前 | 天气、媒体、装备、旅途、阵容与对手消息 | 士气、状态、开场体力 |
| 中场 | 领先保护、落后追分、伤病、牌与更衣室气氛 | 士气、状态、换人建议 |
| 加时 | 体力枯竭、冒险程度、点球手安排 | 体力、关键时刻、心理稳定 |
| 点球准备 | 门将判断、罚球顺序、心理压力 | 点球稳定与选择倾向 |

更衣室状态通过以下上限进入关键决策：

`bonus = clamp((morale - 70) × 0.004 + (form - 70) × 0.003, -0.07, +0.07)`

这意味着一次讲话最多产生正负 7 个百分点的方向性影响，不会变成“选一句台词就必胜”。

### 7.2 两套天气系统

| 天气 | 视听表现 | 专属准备 | 比赛影响方式 |
| --- | --- | --- | --- |
| 晴天 | 正常球场光照与基础环境声 | 常规赛前流程 | 作为比赛基线 |
| 雨天 | 像素雨层、本地双层雨声、湿滑氛围 | 雨战预警、长钉鞋/地面传导选择 | 增加湿滑铲抢等专属决策，不暗改比分 |

天气的变化必须让玩家看见并能准备。它不使用不可解释的“雨天全队 -20%”，而是通过环境、装备、传球思路和专属风险节点进入比赛。

## 八、11v11 比赛与权威事件链

### 8.1 比赛不是背景动画

正式比赛由双方各 11 名运行时球员组成。球员按阵型锚点持续跑位，拥有持球、传球、射门、压迫、铲抢、扑救、犯规、红黄牌、伤病和体力状态。玩家可以选择教练模式进行临场指挥，也可以在玩家模式中直接控制球员。

### 8.2 同一事件同时驱动画面与数据

| Runtime 事件 | 画面反馈 | 正式统计/状态 |
| --- | --- | --- |
| 传球与直塞 | 球路、接应、阵型推进 | 控球与进攻阶段推进 |
| 射门 | 球员动作、球门与门将反应 | 射门、射正、进球 |
| 扑救 | 门将扑救动画与音效 | 扑救、射正未进 |
| 犯规 | 倒地、裁判与哨声 | 犯规、任意球或点球 |
| 黄牌/红牌 | 裁判展示与球员离场 | 纪律统计、场上人数、后续停赛 |
| VAR | 回看提示与判定 | 进球/点球是否成立 |
| 换人 | 场边换人与号码变化 | Runtime actor 身份与体力正式替换 |
| 进球 | 球网、庆祝、比分牌与音效 | 比分、球员进球、事件日志 |

比分、播报、统计和画面以同一事件为权威来源，避免“画面踢了一套，后台又算一套”。稀有事件宁可少出现，也不通过瞬移或假播报硬凑戏剧性。

### 8.3 换人系统

| 规则 | 当前设计 |
| --- | --- |
| 可换人数 | 最多 5 人 |
| 换人窗口 | 最多 3 个正式窗口 |
| 操作方式 | 可一次排队多个换人，再在窗口统一确认 |
| Runtime 同步 | 替补接管正式场上 slot 与业务 actor 身份 |
| 资格限制 | 伤停、不可用球员不能上场；换下者不能重新登场 |
| 比赛作用 | 带入新体力、状态、能力和位置匹配，改变下半场强度 |

## 九、关键决策系统

### 9.1 当前规模与覆盖

53 个场景包含 126 个可选动作、400 条结果分支、70 条导演路径。171 个结果带有明确中文解说；34 条传球分支可继续进入射门；63 条射门分支使用原生足球物理和门将 AI。

| 决策大类 | 覆盖内容 | 可能写入的正式结果 |
| --- | --- | --- |
| 进攻组织 | 直塞、套上、转移、倒三角、低位反击 | 传球推进、射门、角球、进球 |
| 射门与定位球 | 单刀、远射、任意球、点球、头球、补射 | 射门、射正、门柱、扑救、进球 |
| 防守 | 门将 1v1、最后一人、角球防守、越位陷阱、门线解围 | 解围、抢断、犯规、牌、失球 |
| 比赛管理 | 领先保护、落后压上、体力危机、轻伤坚持 | 战术、体力、换人、风险变化 |
| 裁判与 VAR | 越位进球、禁区手球、假摔、点球复核 | 进球有效、取消、点球、牌 |
| 特殊时刻 | 点球大战、补时门将前插、湿滑铲抢 | 高风险机会、纪律与天气后果 |

### 9.2 决策成功率不是固定按钮概率

决策会读取关键球员、对手防守、比分、时间、淘汰赛阶段、体力、状态、士气和场景条件。简化表达为：

`P = clamp(基础概率 × 体能 × 关键属性 × 对手质量 + 士气/状态修正 + 情境修正, 0.10, 0.90)`

每个选项不仅成功率不同，失败代价和成功收益也不同。保守选项可能更稳定但收益较小；冒险选项可能制造进球，也可能直接送给对手反击、点球或红牌。

### 9.3 决策如何改变比赛

| 场景示例 | 选择差异 | 可能后果 |
| --- | --- | --- |
| 单刀 | 推远角 / 挑射 / 过门将 | 进球、被扑、偏出或丢失球权 |
| 3 打 2 反击 | 直塞 / 分边 / 自己推进 | 射门质量、越位、回防形成 |
| 最后一人防守 | 放铲 / 延误 / 战术犯规 | 抢断、单刀、黄牌或红牌 |
| 危险任意球 | 直接打门 / 传中 / 战术配合 | 进球、扑救、争顶与二点球 |
| 领先末段 | 回收 / 保持 / 继续压上 | 控球、体耗、失球风险与反击机会 |
| 补时角球 | 门将留守 / 门将前插 | 保住平局或制造最后一次人数优势 |
| 湿滑铲抢 | 放铲 / 跟防 / 封线路 | 抢断、犯规、牌或被突破 |

## 十、赛后复盘、教练建议与图鉴

### 10.1 教练建议与复盘

赛后系统读取本场射门、射正、进球、控球、犯规、红黄牌、体力、换人和关键选择，给出下一场可执行的建议。它不会修改已经结束的比赛，也不会偷偷给下一场加胜率；提升来自玩家根据建议真正改变阵型、首发、换人、纪律或决策。

| 复盘信号 | 可能建议 | 采用建议后改变的正式输入 |
| --- | --- | --- |
| 射门多、射正少 | 提高终结质量，调整锋线或射门选择 | 首发前锋、关键决策 |
| 控球高但机会少 | 增加宽度、前插或更直接的传球 | 阵型与战术姿态 |
| 下半场明显失势 | 提前换人，降低压迫体耗 | 换人时机与战术 |
| 牌过多 | 减少战术犯规与冒险铲抢 | 防守决策 |
| 定位球失分 | 增加高点、改变盯人与门将安排 | 首发结构与阵型 |
| 点球方向被扑 | 使用情报中的门将倾向 | 点球选择 |

### 10.2 图鉴与收集

图鉴记录每支球队最好成绩、冠军历史、完整征程、累计比赛、进球、零封、连胜和冠军阵型。22 组成就让玩家在夺冠以外拥有长期目标。

| 成就方向 | 代表内容 |
| --- | --- |
| 冠军与多周目 | 初次夺冠、三冠、五冠、多支球队冠军 |
| 比赛表现 | 帽子戏法、五球、连续零封、补时绝杀、逆转 |
| 点球与门将 | 五罚全中、单场扑出三粒点球 |
| 战术与换人 | 三种阵型夺冠、替补累计进球 |
| 征程管理 | 无伤夺冠、小组全胜、连续不败、全胜夺冠 |
| 国家故事 | 东道主夺冠、佛得角/库拉索爆冷、八队参赛 |

图鉴的作用是让失败也留下东西。用强队夺冠后，玩家会想用弱队完成更低但更难的现实目标；用一种阵型通关后，会为了战术成就尝试另一种结构。

## 十一、核心比赛算法

### 11.1 角色评分

| 场上角色 | 属性权重 |
| --- | --- |
| 门将 GK | 防守 55% + 身体 25% + 速度 20% |
| 后卫 DF | 防守 58% + 身体 22% + 速度 12% + 体力 8% |
| 中场 MF | 技术 45% + 防守 25% + 体力 20% + 速度 10% |
| 前锋 FW | 技术 45% + 速度 30% + 身体 15% + 体力 10% |

### 11.2 三线评分与总评

| 评分 | 计算结构 |
| --- | --- |
| 进攻 | 前锋单元 × 0.72 + 中场单元 × 0.28 |
| 中场 | 中场单元 × 0.68 + 后卫单元 × 0.17 + 前锋单元 × 0.15 |
| 防守 | 后卫单元 × 0.68 + 门将单元 × 0.18 + 中场单元 × 0.14 |
| 总评 | 进攻 × 0.32 + 中场 × 0.26 + 防守 × 0.42 |

防守权重最高，是因为错误防线会同时扩大对手机会数量与进球概率，而进攻端仍可通过决策和临场调整制造高质量机会。

### 11.3 防守完整性

`完整性 = clamp(0.42 + 后卫覆盖率×0.38 + 天然门将修正 - 错位后卫×0.07 - 全队错位×0.025, 0.18, 1.04)`

天然门将提供正向结构修正；非门将客串会受到重罚。后卫数量不足、后卫错位和全队错位都会降低完整性，因此把 11 个最高分球员随意塞上场不是稳定最优解。

### 11.4 对手机会与进球压力

| 输入 | 对机会/失球的作用 |
| --- | --- |
| 对手进攻与本方防守差 | 差距越大，对手机会越多 |
| 防守完整性风险 | 防线结构差会同时提高机会与进球概率 |
| 后卫覆盖风险 | 后卫不足使禁区与二点球更危险 |
| 错位数量 | 增加协防与出球失误 |
| 球队难度压力 | 保留强弱队差异 |
| 稳定后防系数 | 天然门将与完整覆盖获得额外稳定性 |

## 十四、玩家选择作用的 A/B 验证

### 14.1 阵容、换人、战术与决策

以下为法国对巴西的方向性开发模型样本，同一随机种子用于比较机制差异：

| 方案 | 胜率 | 场均进球 | 相对基线解读 |
| --- | ---: | ---: | --- |
| 平衡选择 + 正常换人 | 84.7% | 3.49 | 对照基线 |
| 关闭换人 | 78.7% | 2.62 | 胜率 -6.0pp，后程输出下降 |
| 错误阵容 | 55.3% | 2.46 | 胜率 -29.4pp，位置与结构非常关键 |
| 压上战术 | 86.7% | 4.17 | 进球提升，同时承担更高风险和体耗 |
| 落位防守 | 88.3% | 2.89 | 该对阵下更稳，但并非所有对手都最优 |
| 最优概率选择 | 88.0% | 3.58 | 比平衡选择更高，但收益受场景组合影响 |
| 最差概率选择 | 86.0% | 3.37 | 单次样本仍受随机波动，需结合大样本继续验证 |

决策选择的“最优/最差”不应只看表面成功率，因为有些低概率选项收益更高，有些高概率选项只保住球权。当前 A/B 显示决策层能改变结果，但也提醒后续需要按风险收益而非单一成功率重新定义策略标签。

### 14.2 后勤收益

| 配置 | 场均胜率 | 夺冠率 | 相对无后勤 |
| --- | ---: | ---: | ---: |
| 无后勤 | 64.7% | 8.1% | 基线 |
| 医疗 Lv3 | 67.5% | 12.8% | 胜率 +2.8pp |
| 营养 Lv3 | 68.9% | 12.3% | 胜率 +4.2pp |
| 心理 Lv3 | 68.2% | 10.0% | 胜率 +3.5pp |
| 训练 Lv3 | 73.8% | 18.2% | 胜率 +9.1pp |
| 四类直接部门全 Lv3 | 82.7% | 41.5% | 胜率 +18.0pp |

该模拟用于证明后勤不是空菜单，不代表一届赛事可以无成本升满全部部门。正式游戏仍受到资源、升级顺序和比赛数量限制。

### 14.3 情报与建议的转化收益

| 验证项 | 对照 | 样本结果 | 因果路径 |
| --- | --- | ---: | --- |
| 门将弱侧射门 | 针对弱侧 vs 盲射 | 87.8% vs 79.0%，+8.8pp | 情报 → 点球方向 → 正式扑救判定 |
| 阵型克制 | 推荐反制 vs 非反制 | 总体约 +2.9pp | 情报 → 更换阵型 → 正式阵容评分 |

## 十六、视听与移动端设计

### 16.1 像素视觉原则

| 元素 | 设计原则 |
| --- | --- |
| 色彩 | 米黄、深蓝、红、金和棕为主；每支球队保留自己的主色 |
| 字体 | Zpix 像素字体承担数字与强调信息；中文保持清晰可读 |
| 卡片 | 国家队卡、球员卡和聘书在手机端整体缩放，不拆坏像素构图 |
| 动效 | 短促、硬边、可读；重要结果优先于装饰动画 |
| 比赛 | 俯视球场、号码球员、球路、球网和裁判事件共同构成现场感 |

### 16.2 移动端原则

桌面端布局是视觉基准，手机端以整体缩放与局部交互优化为主：国家队卡和球员卡保持原比例；聘书整体缩放以固定印章落点；战术板保留拖拽；比赛情报默认收起，展开后自然把球员列表下推；两个更衣室选项居中；比赛按钮保持可触达但不占满屏幕。

### 16.3 音效与反馈

比赛包含开场与终场哨、环境声、射门、门柱、扑救、进球、牌、换人和雨声等反馈。音效、音乐与震动可独立开关；本地资源保证断网时仍能完整演示。

## 十八、版本范围与后续调优

### 18.1 当前正式范围

当前项目以 16 支可执教国家队为完整版本，不再扩展为 48 支可玩队。世界杯赛程仍保留 48 队对手数据，以维持分组和淘汰赛世界感；正式美术、球员和深度玩法集中投入 16 队。

### 18.2 完整版与互动空间版

| 版本 | 资源策略 | 当前体积口径 |
| --- | --- | ---: |
| 完整版 | 保留 16 队正式资源、比赛 Runtime、点球、音效与全部玩法 | `dist/` 解压约 122 MiB |
| 当前发布 ZIP | 完整版压缩包 | 82.25 MB（78.44 MiB） |
| 互动空间候选版 | 从同一源码按白名单裁剪非演示队与非首屏资源 | 目标低于 50 MB |

互动空间小包不会反向破坏正式版。资源裁剪必须以引用扫描、运行时审计和完整流程测试为前提，不能因为体积压力盲删比赛画面、球衣或 Runtime 数据。

### 18.3 明确保留的工作边界

1. 球队技能的数据与 UI 合同完整，但仍需完成 16 队逐项 Runtime A/B。
2. 道具装备的公平规则与效果意图已经定义，正式库存消耗链仍需接入。
3. 当前场均进球和 5 球以上比赛占比偏高，后续应降低决策进球叠加和高比分尾部。
4. 互动空间版本需要单独的资源白名单与上传验证，不能把本地构建通过等同于平台上传通过。

## 十九、结语

《剑指美加墨》的核心不是菜单数量，而是每一次决定都有来处、有代价、有现场、有结果，也有下一场可以改进的方向。玩家最终记住的不只是像素球场，而是自己如何用一支现实中留下遗憾的球队，重新走过征召、压力、逆境和决胜时刻。

如果那一天由我执教，会不会不一样——这就是游戏希望交给世界杯球迷的第二次机会。
