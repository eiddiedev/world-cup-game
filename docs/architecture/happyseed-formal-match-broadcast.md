# HappySeed 正式全屏比赛页与转播叠层

## 视觉与产品定位

阶段 6 把 `happyseed-runtime.html` 的默认入口从技术实验室切换为正式全屏比赛画面。像素球场、看台、观众和 11v11 Runtime 始终是唯一主视觉，React 只叠加电视转播式信息层，不再常驻大块诊断面板。

视觉原则：

- 夜场像素世界杯是视觉锚点；首屏不使用卡片拼图或后台仪表盘结构。
- 顶部只保留小型比分、比赛时间和双方人数。
- 球场上方只显示最近 2-3 行事件播报，关键进球或危险事件强化颜色。
- 统计、换人与低性能设置均按需展开；关闭时不遮挡球场。
- 入口、播报和抽屉使用短促位移/淡入反馈；低性能模式和 `prefers-reduced-motion` 可全部关闭动效。

技术实验室仍保留在 `happyseed-runtime.html?lab=1`，用于阶段 2-5 回归，不作为正式比赛页面默认形态。

## 权威比赛视图

`src/utils/matchBroadcast.js` 将 Runtime 快照与阶段 5 的 `MatchVisualEvent` 权威状态投影为正式比赛视图：

- 比分只读取 `visualEvents.authority.score`，不读取第三方 Runtime 原生比分。
- 控球率读取连续 Runtime 快照；射门、射正、传球成功率、角球、犯规和牌数读取统一事件权威统计。
- 事件播放时只显示 `commentary.prelude`；Runtime 完成后才显示 `commentary.result`，并把比分与统计结算到页面。
- 页面最多保留最近三条已完成播报；当前 active event 占用最后一行，不产生另一套随机解说。
- `playVisualEventThroughRuntime()` 已调整为 Runtime 完成 Promise resolve 后再执行幂等权威结算。

五事件统计合同补充：

- 常规进攻记录完成传球/尝试传球，正式页面据此计算传球成功率。
- 禁区犯规事件同时给进攻方记录造犯规/点球，给防守方记录犯规/黄牌。
- `opponentStatsDelta` 与 `statsDelta` 一样只由权威玩法层应用。

## 正式页面结构

`src/components/HappySeedMatchBroadcast.jsx` 负责：

- 全屏 Runtime 容器与轻量暗角。
- 小型比分牌、比赛时间、双方人数。
- `aria-live` 的 2-3 行统一事件播报。
- 暂停/继续、1x-3x、精简数据和省电控制。
- 右下固定的小型换人入口。
- PC 侧边抽屉、手机横屏双栏换人面板和 safe-area 适配。

阶段 6 关闭时默认加载会自动串行五个代表事件。阶段 7 起，默认入口改为正式教练限时决策闭环；`?events=auto` 保留本阶段五事件自动串行回归，`?events=manual` 保留不自动触发的人工验收入口。

## 精简统计

统计抽屉只展示比赛决策需要的八项：

- 控球率
- 射门
- 射正
- 传球成功率
- 角球
- 犯规
- 黄牌
- 红牌

抽屉与换人面板互斥，避免两个覆盖层同时占用球场。

## 换人入口与资格

`buildBroadcastSubstitutionBoard()` 消费阶段 4 actor 快照：

1. 先选当前在场的本方 actor。
2. 替补席只显示在场位置兼容候选；门将只允许门将互换。
3. 再选替补并确认，调用适配层 `substituteRuntimeActor()`。
4. 换人沿用原 Runtime 槽位；业务 ID、号码、贴图和状态一次替换。
5. 已换下球员进入 inactive，不返回替补席，不可再次上场。

阶段 6 固定保留现有每场 3 次换人规则。阶段 8 若统一规则数量，只改权威比赛配置，不改两步交互与资格合同。

## 性能与网络边界

- 低性能模式关闭观众动态，并移除转播层动画与阴影。
- 球场适配器在每个 Runtime frame 后重新隐藏第三方 `fans._fansContainer`，只保留人类像素观众图集；`hideLegacyAnimalCrowd` 是场景合同和资源审计的强制不变量。
- 不新增二进制美术资源，不复制球场、人物或球衣贴图。
- 页面离线可运行；火山引擎 AI 后续只能增强播报文案，必须保留本地 `MatchVisualEvent.commentary` fallback。
- 不引入 WebSocket、实时 PVP、实时点球或任何核心联网依赖。

## 阶段 6 关闭门槛

- 默认入口显示正式转播层，`?lab=1` 仍能回归阶段 2-5 实验室。
- 五事件自动串行时，播报从前奏切换为结果，最终权威比分 1:0、统计与事件一致。
- 精简统计可展开/关闭，不与换人抽屉同时显示。
- 换人两步选择在浏览器中精确替换目标 actor，剩余次数与替补数更新，已换下球员不可返场。
- PC 横屏与手机横屏下比分、播报、控制和换人均不遮挡核心球场；省电模式可用。
- 全量测试、lint、三套资源审计、build、包体记录和零 console error 浏览器验收通过。

以上门槛已于 2026-07-13 全部通过，阶段 6 关闭并转入阶段 7 教练决策闭环。
