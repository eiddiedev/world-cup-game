# 剑指美加墨当前 TODO 与接手顺序

更新时间：2026-07-22

## 当前结论

项目已经越过“Runtime 技术切片”阶段，当前处于“教练模式比赛核心收口 + 完整产品剩余玩法开发”的交界处。

已经具备：10 队数据模板、23 人征召、排兵布阵、赛事流程、11v11 正式 Runtime、53 个场内决策、42 个更衣室决策、事件同源播报/音效、换人与战术抽屉、补时、加时赛和互动点球大战。当前最重要的工作不是继续增加随机事件，而是完成真实浏览器验收、修完教练模式的跨场状态，然后进入真正的球员模式。

2026-07-22 维护记录：雨点默认下落速度由 `0.55` 调整为 `0.75`；雨声已由柔和棕噪声替换为“宽频雨幕 + 高频雨滴瞬态”的本地双层合成，并纳入音效开关。无新增音频资产和包体。

## 接手 Agent 开工清单

1. 先读桌面的两份长期文档和 `docs/architecture/` 下的 Runtime、事件源、决策、名单合同。
2. 执行 `git status --short`，不得覆盖用户或其他 Agent 的未提交改动。
3. 执行 `npm ci`、全量测试和审计，记录基线。
4. 只从本文件最上方未完成的优先级开始；不要跳过 P0 直接扩球队或联网。
5. 不修改 `public/match-runtime-min/scripts/match.rebuilt.js`。
6. 每完成一个阶段，更新本 TODO、桌面路线图、资源体积和浏览器验收结果。
