## 当前已实现

- 新增 `match-visual-event-v1`，固定常规进攻、单刀、角球、危险任意球、禁区犯规/点球五种事件。
- 每个事件同时绑定业务 `playerId` 与 `runtimeActorId`，参与者只来自阶段 4 的当前在场 22 人映射。
- 同一事件携带连续球路、镜头、权威比分与统计增量、铺垫/结果播报和 Runtime 完成信号。
- 新增幂等权威结算器；相同事件 ID 只写一次比分、统计与结果播报。
- 新增串行队列；上一事件的 Runtime Promise 完成后才播放下一事件，重复 ID 不再次入队。
- 扩充既有 `CoachDecisionEvent` 到五个代表场景，并按原 `keyPlayers` 精确适配新事件。
- 独立 Runtime 已接入真实 actor 高亮、连续样条球路、镜头与完成事件；只有角球调用已验证的原生 Corner 状态，桥本身不写比分。
- HappySeed 实验页新增事件验收面板，可单独播放、顺序播放或重置五事件，并查看 Runtime 与权威结算快照。
