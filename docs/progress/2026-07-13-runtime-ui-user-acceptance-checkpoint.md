## 建议人工验收顺序

1. 先打开默认入口，观察是否能接受当前球场比例、人物比例、相机和 HUD 作为正式比赛页基础。
2. 至少手动完成一次限时选择，再让下一次自然超时，确认交互节奏是否符合正式版本预期。
3. 五次决策完成后打开“数据”和“换人”，确认球场仍是主视觉，抽屉不会抢占核心画面。
4. 打开 `?events=manual`，只观察连续比赛运动、足球物理、球门、球网和相机，判断第三方 Runtime 是否值得继续接入。
5. 如需检查手机横屏，以 844×390 打开；当前自动验收已确认页面无横向或纵向溢出。
