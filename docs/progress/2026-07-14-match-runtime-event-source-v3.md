# 当前进度看板：Match Runtime 事件同源与决策导演 V3

日期：2026-07-14  
状态：V3 代码、自动门禁和桌面/横屏浏览器验收已完成，等待产品负责人亲自验收；自动通过不等于产品验收通过。

## 产品结论

V2 的通用“足球起点 -> 贝塞尔路径”方案判定为产品验收失败，已经退出正式入口。V3 不再根据 ID、文案或结果正则猜动作，而是让 Runtime 真实事件同时驱动画面、决策、播报与音效。

正式页继续保留明亮单背景像素球场、原 Runtime 球门位置/碰撞/动态球网、11v11 人类角色与自由相机。技术实验室继续保留 V2 供历史对比，但正式页只安装 V3。

## 已完成

### 真实事件流

- 新增 `MatchRuntimeEventV1`、校验器和派生事件 source 合同。
- 适配 Runtime 的触球、传球、射门、球权转换、身体接触、扑救、门柱/横梁、角球、界外球、门球、开球、进球、出界与阶段事件。
- 犯规、伤病、黄牌、手球、VAR、越位和手抛球违例只能绑定真实前置事件；不存在真实违例信号时宁可不播。
- 触发器使用进入条件概率、五窗口预算、事件单占用和场景去重，不传送球员凑场景。

### 53/53 决策导演

- 53 场景按 `30/12/8/3` 四类显式登记。
- 171/171 outcome 均有明确 terminal 和执行分支，无生产 fallback。
- 六种语义表达全部接通；人员、裁判和战术选择不生成球路。
- 实时决策原地冻结；定位球仅在黑场重排；完成后从结果终点继续。
- 30 种球路意图逐项标记 `pass/shot`，修复传中、短传和解围误报射门。
- 导演冻结期间适配层停止第三方 AI simulation tick，继续导演 RAF 与渲染帧；消除 `distanceToBall` 空对象错误，未修改第三方核心。

### 倒计时、播报和音效

- 按标题、说明、风险、收益和成功提示计算 15–25 秒，按钮就绪后开始；后台/暂停/转场期间冻结。
- 正式播报删除分钟轮换虚构文本，只消费 Runtime/规则事件与 settled 决策结果。
- 常规事件有独立预算；连续射门、射门后门球、进球/半场后开球按事件链聚合，全部来源 ID 保留。
- 桌面最近 4 条、`844×390` 最近 3 条，完整历史进入赛后报告。
- 新增事件驱动 `MatchSfxBus`、触球/射门/门柱瞬态音与 CC0 触球/欢呼素材；WebAudio 离线 fallback 保留。

### 正式比赛与 Lab

- 三分钟有效比赛、决策期间比赛钟冻结；实际整场时长由决策阅读和执行时间自然延长。
- 正式 `FormalMatchSession` 继续统一分钟、比分、统计、5 次左右决策和赛后报告。
- Lab 新增 53 场景、choice 和 171 outcome 逐项直达；不恢复正式 `decisionCatalog=1`。
