# 阶段 6：正式全屏比赛页与比赛播报

日期：2026-07-13  
状态：已完成；正式页面、统一播报、精简统计、换人抽屉与桌面/手机横屏浏览器验收全部关闭。

## 当前已实现

- `happyseed-runtime.html` 默认显示正式全屏比赛页；阶段 2-5 实验室保留在 `?lab=1`。
- 球场与 11v11 Runtime 继续全屏渲染，React 只叠加小型比分、时间、状态与操作入口。
- 正式比分使用 `MatchVisualEvent` 权威状态；Runtime 完成后才结算比分、统计与结果播报。
- 2-3 行比赛播报直接使用事件的真实球员、分钟、前奏和结果，进球/危险事件具有强化样式。
- 精简统计包含控球、射门、射正、传球成功率、角球、犯规和红黄牌；数据抽屉与换人抽屉互斥。
- 右下换人入口支持触屏“先选场上球员、再选替补球员”，门将同位与已换下不得返场规则保持不变。
- PC 使用右侧换人抽屉；手机横屏使用双栏场上/替补布局，并覆盖 safe-area。
- 省电模式关闭观众动态与叠层动画；系统减少动态偏好也会禁用动画。
- 页面默认自动串行五个代表事件；`?events=manual` 保留人工测试控制。
- 适配器每帧隐藏第三方 Runtime 的旧动物观众容器，只保留 `world-cup-night-v1` 人类观众层；该约束已写入场景合同与资源审计。
